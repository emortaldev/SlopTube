# YouTube → local apps

Chrome extension that opens YouTube links in the local apps instead:

- music.youtube.com → http://127.0.0.1:8787 (songs, playlists, albums, artists, search)
- youtube.com / youtu.be → http://127.0.0.1:8788 (videos incl. list/t, search, channels incl. @handles, subscriptions, Watch later)

Shorts, live, history, account pages etc. are left on YouTube.
Click the toolbar icon to toggle (badge shows "off").

Install: chrome://extensions → Developer mode → Load unpacked
